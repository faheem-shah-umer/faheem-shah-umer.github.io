# Faheem Shah Umer — Portfolio

This repository contains the source code for [Faheem Shah Umer's portfolio](https://faheem-shah-umer.github.io/).

The website presents My work as an AI, LLM, and mechatronics engineer, with a focus on agentic systems, retrieval-augmented generation, engineering knowledge systems, automotive development, and product engineering.

## What the portfolio includes

- Selected AI, automotive, and mechatronics projects
- Professional experience and education
- An interactive overview of engineering and software technologies
- English and German language options
- A downloadable public résumé
- Contact and LinkedIn links

## Technology

The portfolio is a lightweight, responsive static website built with semantic HTML, CSS, and vanilla JavaScript. It has no framework or runtime dependencies and is published through GitHub Pages.
